# WICS SOFTWARE (CODE)
WICS Wireless Control System  Hard- and Software. Add-On to nowRail. (Last update 2026-07-13)
 
For One-Click Installation of nowRail and WICS software please go to: https://realwireless.github.io/WICS-Install/
-----------------------------------------------------------------------------------------------------------------
To download nowRail and WICS C/C++ code for different WICS Boards:
1. Create the folder \nowRail in your Arduino sketch folder.
2. Download all files from the nowRail folder to your local \nowRail folder.
3. Install ESP32 drivers and the libraries described in "readme.txt" in each WICS_[Board] folder to Arduino IDE.
5. Connect your [Board] to your computer with a "real" USB-C cable.
6. Open nowRail.ino from the Arduino IDE.

Description with sample configuration file ([board].txt) is located in each WICS_[Board] folder.       
To access For WICS PCB Files please go to https://github.com/realwireless/WICS-Hardware
