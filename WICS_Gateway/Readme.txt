Board: ESP32C6 DEV Module
1. Install the Board "esp32" by espressif Systems 
2. Download following Libraries to your Arduino IDE
   -Adafruit GFX library
   -Adafruit SSD1306 library
   -Also install any associated library 
3. In Arduino IDE -> Tools -> "USB CDC On Boot" -> Enabled
